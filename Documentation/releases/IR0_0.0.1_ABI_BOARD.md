**FAT16 rw:** `linux-abi-audit-vfs-write-fat` PASS on dedicated FAT16 audit disk (see `vfs_write_fat` contract).

Fuente ABI dup CLOEXEC: [man 2 dup](https://man7.org/linux/man-pages/man2/dup.2.html).

**ARCH-3 (2026-07-10):** opens de `/proc` y `/sys` (registry + dynamic pid status/cmdline + dirs `/proc/pid`) instalan slots reales en `fd_table` (`is_pseudo` / dir bind). Ya no se asignan fds globales `1001`/`1010`/`1150`/`1151` ni `PSEUDO_FS_*_FD_BASE` a userspace. `PSEUDO_FS_*_FD_BASE` queda como ID interno de tabla registry.

**ARCH-3 residual (2026-07-10):** eliminadas ramas I/O de `FD_SYS_BASE`/`FD_DEV_BASE` (read/write/fstat/getdents/poll/close/lseek/ioctl/ftruncate/mmap fb0). Solo `fd_table` con `is_pseudo` / `is_devfs`. Macros `FD_*_BASE` retirados de `syscalls_glue.h`.
